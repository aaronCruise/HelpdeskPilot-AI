# Projector Troubleshooting

Common Symptoms

- No signal
- Blank screen
- Incorrect input source
- HDMI not detected

Troubleshooting Steps

1. Verify projector power.
2. Verify HDMI cable connection.
3. Verify projector input source.
4. Test alternate cable.
5. Restart connected device.
6. Escalate to Classroom Technology support if unresolved.

Priority

Medium unless classroom instruction is actively disrupted.
